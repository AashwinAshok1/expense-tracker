# Expense Tracker (Python + SQLite)

A simple beginner-friendly command-line application for tracking expenses.  
Built with Python and SQLite, this project demonstrates basic CRUD operations, database integration, and clean project structure.

## Features
- Add expenses
- View all expenses
- Delete expenses
- SQLite database storage
- Beginner-friendly code structure

## Requirements
- Python 3.x

## How to Run
1. Clone the repository:
   git clone https://github.com/YOUR_USERNAME/expense-tracker.git

2. Navigate into the folder:
   cd expense-tracker

3. Run the app:
   python main.py
